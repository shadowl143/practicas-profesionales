# ADR 4.2 — Realizar un crud
**Contexto:** Es necesario realizar un CRUD y que cada uno vea lo suyo en  FBV y CBV
**Opciones:** No existe una opcion a elegir ya que cada uno debe hacer lo mismo.
**Criterio:** no hay un criterio elegir.
**Evidencia:** 
**Decisión:** se va a manejar por medio de funciones ya que los datos se contienen sobre el mismo archivo sin necesidad de realizar herencias, en estos proyectos.
**Consecuencias:** se van a tener mas metodos en el controller por cada uso que se realice
**Me haría cambiar de opinión:** si la aplicacion veo  que contienen mucho codigo reutlizable puedo cambiar y empezar a manejar herencias geneicas para su uso.
